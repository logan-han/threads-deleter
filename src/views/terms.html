What this service does

Threads Deleter deletes posts from the Threads account you connect, using the official Threads API, at the rate that API permits. It acts only on the account that authorised it and only within the job you configured.

Deletion cannot be undone

You confirm before connecting that a live run permanently removes posts. Run the dry run first if you want to check your filters. Once a post is deleted, neither this service nor its operator can recover it.
